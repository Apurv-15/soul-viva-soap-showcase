# Soul-Viva Soap — Luxury Skincare D2C Showcase

> **Live Preview (Vercel):** [https://soul-viva-soap-demo.vercel.app](https://soul-viva-soap-demo.vercel.app)  
> **Client:** Soul-Viva Skincare  
> **Tech Stack:** Next.js, GSAP, Framer Motion, Tailwind CSS

---

## 📌 Project Overview
Soul-Viva Soap is a digital showcase for a premium line of transparent glycerin bathing bars. Designed with 3D cursor parallax depth movement and silky dynamic smooth scrolling, it delivers a tactile, luxury brand experience.

---

## 🚀 Key Engineering Highlights
* **3D Mouse Parallax:** Interactive multi-layered depth effects reacting to user movement.
* **GSAP & Framer Motion Transitions:** Smooth micro-interactions and scroll-triggered animations.
* **Responsive Touch Optimization:** Seamless performance across mobile devices and high-DPI displays.
